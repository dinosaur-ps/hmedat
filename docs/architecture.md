# معمارية النظام

المتصفح يقرأ `/api/catalog` للحصول على المنتجات الظاهرة ومعلومات الموقع. بطاقة المنتج تُنشئ رابط `wa.me` بترميز نص الرسالة الصحيح؛ لا يحتاج ذلك حساب واتساب API أو مفتاحاً سرياً.

لوحة التحكم `/admin` تتصل بنفس الخادم. كل عملية تعديل تمر عبر فحص المصدر وجلسة المدير قبل تنفيذ استعلامات مربوطة المعاملات في D1. الصور المقبولة ترفع إلى R2 بأسماء عشوائية، وتعرض عبر `/api/images/<id>`. لا ينفذ الخادم روابط الصور الخارجية ولا يجلبها؛ المتصفح يعرضها فقط.

الجداول:

- `products`: المعرّف، الاسم، السعر، الصورة، الفئة، الظهور، الترتيب، آخر تحديث.
- `settings`: نصوص الموقع القابلة للتعديل.
- `admins`: حساب المالك وبصمة كلمة المرور وsalt.
- `sessions`: بصمات رموز الجلسات وتاريخ الانتهاء.
- `attempts`: عدادات محاولات الدخول المؤقتة.

إضافة منتج أو تعديله تظهر عند إعادة تحميل واجهة العرض، بدون تعديل ملفات أو إعادة نشر. الإخفاء يحتفظ بالمعلومات في لوحة التحكم ويمنع ظهور المنتج ضمن الكتالوج العام. إعدادات الصفحة الرئيسية كلها محفوظة في جدول `settings`، وتشمل النصوص وصورة الغلاف ورقم واتساب والدومين. عند فتح واتساب، يظهر الاسم والسعر الموجودان في البطاقة وقت تحميلها؛ الموقع لا يحجز مخزوناً أو يضمن السعر بعد تغيير المدير له.

حدود النسخة: حساب مدير واحد، عملة شيكل، لا مخزون أو دفع أو طلبات مسجلة في الموقع. إعدادات اللغة والعنوان عبر النصوص؛ لوحة التحكم بالعربية، وواجهة المتجر بالعبرية كما في النسخة الأصلية.
