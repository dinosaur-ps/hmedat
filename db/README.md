# قاعدة البيانات

النظام مرتبط بقاعدة Cloudflare D1 من خلال الربط `DB` المعلن في
`.openai/hosting.json`. تعريف الجداول المصدر موجود في `schema.ts`، وملف SQL
القابل للتطبيق موجود في `../drizzle/0000_true_firedrake.sql`.

الجداول المستخدمة:

- `products`: المنتجات، السعر، الصورة، الفئة، حالة الظهور وترتيب العرض.
- `settings`: جميع عناصر الصفحة الرئيسية بصيغة مفتاح وقيمة.
- `admins`: حساب المدير وبصمة كلمة المرور المشفرة.
- `sessions`: جلسات لوحة التحكم وتاريخ انتهائها.
- `attempts`: تحديد محاولات تسجيل الدخول.

لا تُضاف المنتجات أو بيانات الدخول داخل ملف الترحيل، حتى يبقى الترحيل هيكليًا
وآمنًا لإعادة الاستخدام. المنتجات تُدار من لوحة التحكم، والإعدادات الافتراضية
موجودة في `lib/repository.ts` ثم تُستبدل بالقيم المحفوظة في جدول `settings`.

عند النشر عبر Sites تُنشأ D1 وتُربط تلقائيًا ويُطبق ملف الترحيل. للتجربة
المحلية اتبع أوامر قاعدة البيانات في README الرئيسي.
